Aeroscapes Reimagine объединяет островное выживание, механизмы Create, летательные аппараты Aeronautics, строительство и кулинарию. Можно обосноваться на большом острове, построить фабрику, оборудовать корабль для экспедиций или путешествовать без постоянного дома.

## Дальнейшее развитие

В сборке планируются [расы, классы и развитие персонажа](experience/character-and-combat/), самостоятельные [магические системы](experience/magic/), [колонии и задания NPC](experience/settlements/). Они дополнят песочницу новыми занятиями и способами путешествовать. На страницах этих направлений отдельно описано, что уже есть и что ещё предстоит добавить.

## Технические требования

| Компонент               | Версия            |
| ----------------------- | ----------------- |
| Minecraft: Java Edition | 1.21.1            |
| Загрузчик               | NeoForge 21.1.230 |
| Java                    | 25                |

Минимальные требования к оперативной памяти и видеокарте пока не определены: опубликованных игровых замеров ещё нет.

Информация о релизах и поддержке находится в разделе [«Релизы и ограничения»](known-issues/).
