description: Установка полученного файла сборки в Modrinth App.

Публичного релиза для скачивания пока нет. Если у вас есть тестовый файл `.mrpack`, его можно импортировать в Modrinth App как новый экземпляр игры.

1. В Modrinth App 0.22.0 откройте общие настройки → **Instance defaults → Java and memory**. В списке установок Java найдите **Java 25 location** и нажмите **Install recommended**. Лаунчер сам скачает Java; отдельно устанавливать системный JDK не нужно.
2. Импортируйте `.mrpack` как новый экземпляр и дождитесь загрузки файлов. В сборке указаны Minecraft 1.21.1 и NeoForge.
3. Откройте настройки этого экземпляра → **Java and memory**, включите **Custom Java installation**, нажмите **Detect** и выберите строку с версией **25**. Дождитесь успешной проверки Java. Одной установки Java 25 в общих настройках недостаточно: для этой версии Minecraft требуется выбор в экземпляре.
4. Запустите экземпляр и создайте мир с обычным типом генерации. В других версиях приложения расположение пунктов может отличаться.

Модуль генерации OpenCL может использовать совместимый GPU и его драйвер OpenCL; если этот путь недоступен, генерация может перейти на CPU. Java 25 нужна в обоих случаях. Перед обновлением прочитайте раздел [«Релизы и ограничения»](../known-issues/) и сохраните резервную копию мира.
